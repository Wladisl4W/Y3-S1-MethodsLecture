# Способы выбора матриц $F_k$

1. $F_k = E, \, k=0,1,$  
   Тогда двойное неравенство (1) выполняется с $r=R=1$. Методы с таким выбором $F_k$ назовем _градиентными_.

2. Пусть $f(\vec{x})$ дважды непрерывно дифференцируема и матрица Гессе этой функции удовлетворяет следующему неравенству:  
   $$m ||\vec{y}||^2 \leq (f''(\vec{x}^{(k)})\vec{y}, \vec{y}) \leq M ||\vec{y}||^2 \, \forall \, \vec{y} \in E^n, \, 0<m<M \tag{2}$$  
   $$r ||\vec{y}||^2 \leq (F^{(k)}\vec{y}, \vec{y}) \leq R ||\vec{y}||^2, \tag{3}$$  
Из неравенства (2) $\Rightarrow$, что существует матрица $F_k$, обратная матрице Гессе  
   $$F_k = [f''(\vec{x}^{(k)})]^{-1}$$  

Матрица $F_k$ удовлетворяет двойному неравенству (1) с $r = \frac{1}{M}, \, R = \frac{1}{m}$.  

Методы с таким выбором $F_k$ назовем _методами Ньютона_ или _обобщенными методами Ньютона_.

3. Другие способы выбора $F_k$.

# Метод Дэвидона-Фитчера-Гауэлла

Если $f'(\vec{x})$ считается численно (обратно тоже численно), мы получаем разницу аналог метода Ньютона. Существующий метод называется методом Дэвидона-Фитчера-Гауэлла, в котором вначале используется градиентный метод, а затем метод ньютоновского типа. При этом матрица Гессе не рассчитывается, а сразу находится в приближении к обратной матрице Гессе.

# Алгоритмы определения шага $\alpha$

## Алгоритм 1 (с постоянным шагом)

Пусть задано некоторое начальное приближение $\vec{x}^{(0)}$ и каким-то образом посчитаны  
$$\vec{x}^{(1)}, \quad \vec{x}^{(2)}, \ldots, \quad \vec{x}^{(n)}$$  
Пусть  
$$\alpha = const > 0, \quad \text{следовательно}$$  
$$\vec{x}^{(k+1)} = \vec{x}^{(k)} + \alpha F_k (-\nabla f(\vec{x}^{(k)})).$$

**Например,**  
$$\alpha \equiv 1.$$

## Алгоритм 2

Выберем произвольное начальное приближение $\vec{x}^{(0)}$ и некоторое число  
$$\delta \in (0,1).$$  
Пусть  
$$\alpha = 1.$$

1. Вычислим вектор  
   $$\vec{x} = \vec{x}^{(0)} - \alpha F_0 \nabla f(\vec{x}^{(0)}),$$  
   посчитаем значение функции $f(\vec{x})$, проверим, выполняется ли неравенство (3)
   $$f(\vec{x}) - f(\vec{x}^{(0)}) \leq -\alpha \delta r ||\nabla f(\vec{x}^{(0)})||^2$$  
  2. Если неравенство (3) выполняется, то полагаем $x_1 = x$, иначе $\alpha = \frac{\alpha}{2}$ переходит к пункту 1.

---

# Теорема о корректности алгоритма

**Теорема**

Пусть $\vec{x}^{(0)}$ не критическая точка, матрица $F_k$ и $f''(\vec{x})$ удовлетворяют неравенствам (1) и (2) соответственно. Тогда после некоторого конечного числа дроблений $\alpha$ неравенство (3) будет выполняться, т.е. алгоритм 2 корректен.

## Доказательство:

Определим точки вида $\vec{x} = \vec{x}_0 - \alpha F_0 \nabla f(\vec{x}^{(0)})$, где $\alpha$ пока не определено. Вычислим значение  

$$f(\vec{x}) - f(\vec{x}^{(0)}) =$$

$$= (\nabla f(\vec{x}^{(0)}), -\alpha F_0 \nabla f(\vec{x}^{(0)})) + \frac{1}{2} (f''(\vec{x}^{(0)}) (-\alpha F_0 \nabla f(\vec{x}^{(0)}))^2) \leq$$

$$\leq -\alpha r (||\nabla f(\vec{x}^{(0)})||^2 + \alpha^2/2M (||F_0 \nabla f(\vec{x}^{(0)})||^2) \leq$$

$$\leq -\alpha r (||\nabla f(\vec{x}^{(0)})||^2 + \alpha^2/2MR^2 (||\nabla f(\vec{x}^{(0)})||^2) \leq$$

$$\leq -\alpha r (1 - \frac{\alpha MR^2}{2}) (||\nabla f(\vec{x}^{(0)})||^2)$$

Требуемое неравенство выполняется, как только  

$$1 - \frac{\alpha MR^2}{r} > \delta = 1 - \delta > \frac{\alpha MR^2}{r} = \alpha < \frac{(1-\delta)2r}{MR^2} < 1 - \delta$$

# Замечание к алгоритму и Алгоритм 3

**Замечание.** В алгоритме есть число $\delta \in (0,1)$. Выбором $\delta$ для конкретной функции можно ускорить итерационный процесс. Если нет определенной информации, то $\delta = 0.5$

**Алгоритм 3.**

Пусть задано некоторое начальное приближение $\vec{x}^{(0)}$ и каким-то образом рассчитаны $\vec{x}^{(1)}, \vec{x}^{(2)}, \ldots, \vec{x}^{(k)}$.

1) Определим точки вида  
$$\vec{x}^{(k+1)} = \vec{x}^{(k)} + \alpha F_k(-\nabla f(\vec{x}^{(k)})),$$ где только $\alpha$ не определено.

2) Введем функцию $g(\alpha) = f(\vec{x}) - f(\vec{x}^{(k)}) + \alpha F_k(-\nabla f(\vec{x}^{(k)}))$, которая будет являться функцией одного переменного для $\alpha$, находим минимум функции на отрезке $(0,1)$ с помощью методов одномерной оптимизации.

3) Получаем $\alpha_k$ и вычисляем $\vec{x}^{(k+1)} = \vec{x}^{(k)} + \alpha F_k(-\nabla f(\vec{x}^{(k)}))$.

# Метод градиентного спуска

Процедура построения последовательности $(\vec{x}^{(k)})$ организована следующим образом:  
$$\vec{x}^{(k+1)} = \vec{x}^{(k)} + \alpha^{(k)}\vec{y}^{(k)}, \, k=0, 1, 2, \ldots,$$  
$$\vec{y}^{(k)} = -\nabla f(\vec{x}^{(k)}),$$  

где величины шага спуска $\alpha^{(k)} > 0$ выбираются достаточно малыми для того, чтобы выполнялось условие последовательного убывания значений целевой функции $f(\vec{x})$ в точках $\vec{x}^{(k)}, \, k=0, 1, 2, \ldots$.  

**Теорема 9.** Пусть функция $f(\vec{x})$ ограничена снизу, дифференцируема на $R^n$ и ее градиент $\nabla f(\vec{x})$ удовлетворяет условию Липшица с постоянной $L>0$:  
$$\| \nabla f(\vec{x}') - \nabla f(\vec{x}'') \| \leq L \| \vec{x}' - \vec{x}'' \| \text{ для } \forall \vec{x}', \vec{x}'' \in R^n.$$  
Тогда для любой начальной точки $\vec{x}^{(k)}$ в итерационной процедуре:  
$$\vec{x}^{(k+1)} = \vec{x}^{(k)} + \alpha\vec{y}^{(k)}, \, (3)$$  
$$\vec{y}^{(k)} = -\nabla f(\vec{x}^{(k)}), \, k=0, 1, 2, \ldots.$$  

можно выбрать такое число $\alpha > 0$, постоянное для всех $k$, что  
$$\lim_{k \to \infty} \| \nabla f(\vec{x}^{(k)}) \| = 0,$$  
причем последовательность $(\vec{x}^{(k)})$ будет релаксационной.

---

# Теорема о сходимости (продолжение)

**Замечание.** Теорема гарантирует сходимость последовательности $f(\vec{x}^{(k)})$:

— либо к значению функции $f(\vec{x})$ в некоторой стационарной точке $\vec{x}^*$;

— либо к точной нижней грани $\inf(f(\vec{x}) : \vec{x} \in R^n)$, при этом не исключается случай, когда ничего определенного сказать о сходимости последовательности $(\vec{x}^{(k)})$ нельзя.

**Теорема 10.** Пусть функция $f(\vec{x})$ ограничена снизу, дифференцируема на $R^n$ и ее градиент $\nabla f(\vec{x})$ удовлетворяет условию Липшица с постоянной $L > 0$:

$$ ||\nabla f(\vec{x}') - \nabla f(\vec{x}'')|| \leq L ||\vec{x}' - \vec{x}''|| \text{ для } \forall \vec{x}', \vec{x}'' \in R^n$$ и существует постоянная $C$, такая что множество уровня

$$ L(C) = \{\vec{x} \in R^n : f(\vec{x}) \leq C\} \text{ не пусто и компактно.}$$ Тогда для любой начальной точки $\vec{x}^{(0)} \in L(C)$ последовательность $(\vec{x}^{(k)})$, определенная по формуле (3), будет релаксационной, причем каждая ее предельная точка $\vec{x}^*$ удовлетворяет $\nabla f(\vec{x}^*) = 0$.

**Следствие.** Если дополнительно функция $f(\vec{x})$ выпукла, то всякая предельная точка последовательности $(\vec{x}^{(k)})$ будет точкой минимума функции $f(\vec{x})$ на $R^n$.

# Анализ метода градиентного спуска

1. Итерационная процедура спуска (3) с постоянным шагом $\alpha = const$ удобна, но при реализации требует знания величины шага $\alpha$, которая на практике определяется подбором. При этом выбор большого шага $\alpha$ может привести к нарушению условия убывания целевой функции  

$$f(\vec{x}^{(k+1)}) = f(\vec{x}^{(k)} + \alpha\vec{y}^{(k)}) < f(\vec{x}^{(k)}) \tag{4}$$  
С другой стороны, достаточно малый шаг обеспечит выполнение неравенства (4), но для достижения требуемой точности потребуется большое количество итераций. Поэтому сначала фиксируют некоторое значение шага спуска $\alpha > 0$ и производят вычисления по формуле (3). При этом если неравенство (4) не выполняется, то для текущей итерации величину шага спуска уменьшают (дробят) до тех пор, пока условие убывания функции (4) не будет выполнено, и продолжают вычисления.

---

# Условия окончания процедуры спуска

2. **Условие окончания процедуры спуска.** Выполняется требование на точность решения задачи минимизации, например  
$$\|\vec{x}^{(k+1)} - \vec{x}^{(k)}\| \leq \epsilon_1,$$
или  
$$|f(\vec{x}^{(k+1)}) - f(\vec{x}^{(k)})| \leq \epsilon_2,$$
где $\epsilon_1 > 0$, $\epsilon_2 > 0$ - заданные заранее числа.  
Учитывая условия (3), получим:  
$$\|\vec{x}^{(k+1)} - \vec{x}^{(k)}\| \leq \alpha\|\vec{y}^{(k)}\| = \alpha\|\nabla f(\vec{x}^{(k)})\|$$
отсюда следует, что можно использовать в качестве условия окончания итерационной процедуры градиентного спуска неравенства:  
$$\frac{\partial f(\vec{x}^{(k)})}{\partial x_l} \leq \epsilon_3, \quad l = 1,2,...,n,$$
или  
$$\|\nabla f(\vec{x}^{(k)})\| \leq \epsilon_3, \epsilon_3 > 0.$$

3. **Выбор решения.** В качестве приближения для $\vec{x}^*$ принимается последняя вычисленная точка $\vec{x}^{(k)}$. Тогда значение $f(\vec{x}^{(k)})$ приближенно определяет величину $f^* = f(\vec{x}^*)$.

---

# Алгоритм наискорейшего градиентного спуска

Для нахождения локального минимума функции $f(\vec{x})$ строится последовательность точек $\vec{x}^0, \vec{x}^1, ..., \vec{x}^n$ по правилу $\vec{x}^{k+1} = \vec{x}^k + \alpha_k \vec{S}^k$, где $\vec{S}^k = -\nabla f(\vec{x}^k)$.

Пусть задано начальное приближение $\vec{x}^0$, точность $\delta > 0$ и $\epsilon > 0$, а также предельное число итераций $N$.

Помимо предельного числа итераций, в качестве условия окончания принимается выполнение необходимого условия экстремума $\nabla f(\vec{x}^*) = 0$, а для численной реализации — это эквивалентно выполнению неравенства $||\nabla f(\vec{x}^*)|| < \delta$, где $\vec{x}^k$ — приближенное численное решение задачи $f(\vec{x}) \to \min$.

Кроме того, используется дополнительное условие выполнения неравенств $||\vec{x}^{k+1} - \vec{x}^k|| < \epsilon$, $|f(\vec{x}^{k+1}) - f(\vec{x}^k)| < \epsilon$, которые должны выполняться одновременно подряд на $k-1$ и $k$- шаге. Это условие необходимо для овражных (сильно вытянутых) функций, когда итерационный процесс происходит вблизи точки минимума, но заданная точность $\delta > 0$ еще не достигнута.

---

# Алгоритм наискорейшего градиентного спуска

1. Вычислим $\nabla f(\vec{x}^0)$.

2. Проверим выполнение неравенства $\| \nabla f(\vec{x}^0) \| < \delta$:

a) если условие выполнено, то $\vec{x}^* = \vec{x}^0$;

б) в противном случае, переходим на следующий шаг.

3. Положим $k=0$

4. Найдем $\vec{x}^{k+1} = \vec{x}^k + \alpha_k \cdot (-\nabla f(\vec{x}^k))$.

5. Найдем $\alpha_0$ как минимум функции

$$g(\alpha_k) = f(\vec{x}^{k+1}) = f\left( \vec{x}^k + \alpha_k \cdot (-\nabla f(\vec{x}^k)) \right),$$

используя методы одномерной минимизации.

6. Вычислим новое $\vec{x}^{k+1} = \vec{x}^k + \alpha_k \cdot (-\nabla f(\vec{x}^k))$.

---

# Алгоритм наискорейшего градиентного спуска (продолжение)

7. Проверим выполнение условия $\|\vec{x}^{k+1} - \vec{x}^k\| < \varepsilon, |f(\vec{x}^{k+1}) - f(\vec{x}^k)| < \varepsilon$, которые должны выполняться одновременно подряд на $k-1$ и $k$ – шаге:
   a) если условие выполнено, то $\vec{x}^* = \vec{x}^{k+1}$;
   б) в противном случае полагаем $k = k + 1$ и переходим на следующий шаг.

8. Сравниваем $k$ с предельным числом итераций $N$:
   a) если $k \geq N$ выполнено, то $\vec{x}^* = \vec{x}^1$;
   б) в противном случае переходим на первый пункт, вычисляем градиент для новой точки $\vec{x}^1$ и проверяем выполнение неравенства для точки $\vec{x}^1$ и так далее до тех пор, пока не выполнится, по крайней мере, один из критериев окончания расчетов.

---

# Замечания к алгоритму

**Замечание 1:** путём проведения дополнительного исследования определяется, является ли найденная точка $\vec{x}^k$ приближением искомой точкой минимума $\vec{x}^*$. Для этого используется, например, достаточное условие экстремума.

**Замечание 2:** если требуется найти глобальный минимум функции $f(\vec{x})$, то в случае, когда функция имеет несколько локальных минимумов, поиск глобального минимума осуществляется в результате перебора всех локальных минимумов.

# Метод сопряженных градиентов Флетчера – Ривса

Для нахождения локального минимума функции $f(\vec{x})$ также строится последовательность точек $\vec{x}^0, \vec{x}^1, \ldots, \vec{x}^n$ по правилу $\vec{x}^{k+1} = \vec{x}^k + \alpha_k \vec{S}^k$.

Первый шаг выполняется точно также, как и в методе наискорейшего градиентного спуска. Но в отличие от метода наискорейшего спуска вектор $\vec{S}^k$, начиная со второго шага при $k \geq 1$, определяется рекурсивно через вектор $\vec{S}^{k-1}$, полученный на предыдущем шаге, а именно, как $\vec{S}^k = -\nabla f(\vec{x}^k) + \beta_{k-1} \vec{S}^{k-1}$, где  
$$\beta_{k-1} = \frac{\|\nabla f(\vec{x}^k)\|^2}{\|\nabla f(\vec{x}^{k-1})\|^2}.$$

Причем, на первой операции при $k=0$ полагают, что $\vec{S}^0 = -\nabla f(\vec{x}^0)$. Таким образом, первый шаг метода Флетчера–Ривса полностью совпадает с первым шагом метода наискорейшего спуска, т.к. $\vec{x}^1 = \vec{x}^0 + \alpha_0 \cdot (-\nabla f(\vec{x}^0))$, а дальше  
$$g(\alpha_0) = f(\vec{x}^1) = f\left( \vec{x}^0 + \alpha_0 \cdot (-\nabla f(\vec{x}^0)) \right).$$
