# МЕТОД ЗОЛОТОГО СЕЧЕНИЯ

Рассмотрим числа Фибоначчи в виде
$$F_N = \frac{\tau^{n+1} - (1-\tau)^n}{\sqrt{5}}, \quad n \geq k = 0, 1, 2, ..., \tau = (1 + \sqrt{5})/2.$$

Покажем, что при больших значениях $k$ справедливо асимптотическое представление
$$F_N = \frac{\tau^{n+1}}{\sqrt{5}} + O\left(\frac{1}{\tau^{n+1}}\right).$$

Будем выбирать $x$ следующим образом:
$$x = \lim_{N \to \infty} \left( a + \frac{b-1}{b}, b = 0 \right).$$

Вычислим предел
$$\mu_n = \frac{F_{N-1}}{F_N}$$

$$F_N = \frac{\tau^{n+1}}{\sqrt{5}} + O\left(\frac{1}{\tau^{n+1}}\right),$$

$$F_{N-1} = \frac{\tau^n}{\sqrt{5}} + O\left(\frac{1}{\tau^n}\right).$$

Тогда имеем
$$\mu_n = \frac{F_{N-1}}{F_N} = \frac{\tau^n}{\tau^{n+1}} = \frac{1}{\tau} = \frac{\sqrt{5}-1}{2} \approx 0.618034.$$

# Алгоритм метода золотого сечения

В методе золотого сечения на первом шаге выбор точек осуществляется по формулам расчета точек золотого сечения отрезка $[a_0, b_0]$:

$$x_0 = a_0 + \frac{3-\sqrt{5}}{2}(b_0 - a_0);$$

$$y_0 = a_0 + b_0 - x_0.$$

Затем вычисляем значения функции $f(x_0)$ и $f(y_0)$ и сравниваем их. Если $f(x_0) < f(y_0)$, то точка минимума $x^* \in [a_0, y_0]$ и
$a_1 = a_0, b_1 = y_0$. Если $f(x_0) \geq f(y_0)$, то $x^* \in [x_0, b_0]$ и $a_1 = x_0$,
$b_1 = b_0$.

---

# Свойства метода золотого сечения

В итоге в любом случае мы получаем отрезок $[a_1, b_1]$, который обладает следующими свойствами:
1) $x^* \in [a_1, b_1]$;

2) $b_1 - a_1 = y_0 - a_0 = b_0 - x_0 = b_0 - a_0 - \frac{3-\sqrt{5}}{2}(b_0 - a_0) = (b_0 - a_0)(1 - \frac{3-\sqrt{5}}{2}) = (b_0 - a_0)\left(\frac{\sqrt{5}-1}{2}\right)$;

3) новый отрезок локализации $[a_1, b_1]$, помимо точки минимума $x^*$, содержит одну из найденных точек $x_0$ или $y_0$.

# Сходимость метода золотого сечения

Для метода золотого сечения характеристика относительного уменьшения начального интервала неопределенности находится по формуле $R(N) = \left( \frac{\sqrt{5}-1}{2} \right)^{N-1}$, где $N$ — количество вычислений функции.

---

# Достоинства методов оптимизации

1) **Метод дихотомии** численно устойчив, а также прост для программирования.

2) **Метод Фибоначчи** в сравнении с остальными методами дает при одном и том же заданном количестве вычислений функции наименьший отрезок локализации. Для примера рассмотрим характеристики относительного уменьшения отрезка локализации для методов:

Фибоначчи $R_F(N) = \frac{1}{F_N}$ и золотого сечения $R_Z(N) = \left( \frac{\sqrt{5}-1}{2} \right)^{N-1}$ (так как на каждой итерации для данных методов требуется одно вычисление функции). Тогда с учетом $F_N = \frac{\tau^{N+1}}{\sqrt{5}} + O\left( \frac{1}{\tau^{N+1}} \right)$ и $\tau = \frac{1+\sqrt{5}}{2}$ имеем:

---

# Сравнение методов Фибоначчи и золотого сечения

$$\frac{R_F (N)}{R_Z (N)} = \frac{1}{F_N} \div \left( \frac{\sqrt{5}-1}{2} \right)^{N-1} = \frac{\sqrt{5}}{\tau^{N+1}} \div \left( \frac{\sqrt{5}-1}{2} \right)^{N-1} = \frac{\sqrt{5}}{\left( \frac{\sqrt{5}-1}{2} \right)^{N-1} \left( \frac{\sqrt{5}+1}{2} \right)^{N+1}} = \frac{\sqrt{5}}{\left( \frac{\sqrt{5}+1}{2} \right)^2} = \frac{2\sqrt{5}}{3 + \sqrt{5}} \approx 0,854102.$$

3) **Метод золотого сечения** прост для программирования и будет численно устойчив, если после некоторого числа шагов $k$ предусмотреть возможные повторные вычисления $x_k = a_k + \frac{3 - \sqrt{5}}{2} (b_k - a_k)$.

---

# НЕДОСТАТКИ методов оптимизации

1) К недостаткам **метода дихотомии** относится то, что на каждой операции необходимо вычислять два значения функции $f(x_i)$ и $f(y_i)$, тогда как в методах Фибоначчи и золотого сечения только одно – $f(x_i)$ или $f(y_i)$, другое же значение функции берется с предыдущего шага. Таким образом, для нахождения минимума требуется большее по сравнению с остальными методами количество вычислений функции.

2) **Метод Фибоначчи** численно неустойчив, так как ошибки округления быстро накапливаются. Поэтому для численной реализации нахождения минимума он не применяется, а используется для определения наименьшего отрезка локализации при заданном количестве вычислений функции.

# Многомерная оптимизация функций многих переменных

**Определение 1.** Произвольное $n$-мерное линейное пространство называется $n$-мерным евклидовым пространством, если в нем определено скалярное произведение.

При любом значении и в $n$-мерном линейном пространстве $R^n$ можно определить скалярное умножение, т. е. можно превратить это пространство в евклидово.

**Норма** - обобщение длины свободного вектора. Длину вектора в линейном пространстве $R_1$ или $R_2$ можно рассматривать как функцию, определенную на множестве $R_1$ или $R_2$, которая каждому вектору рассматриваемого линейного пространства ставит в соответствие его длину.

Норму вектора в линейном пространстве иногда называют длиной.

---

# Определения нормы и нормированного пространства

**Определение 2.** Функция, заданная на линейном пространстве $L$, которая каждому вектору $\bar{x}$ из $L$ ставит в соответствие действительное число $|\bar{x}|$, называется **нормой**, если она удовлетворяет аксиомам нормы:  
a) $|\bar{x}| \geq 0$, причем $|\bar{x}| = 0$, если $\bar{x} = 0$;  
b) $|\lambda \bar{x}| = |\lambda| \cdot |\bar{x}|$;  
c) $|\bar{x} + \bar{y}| \leq |\bar{x}| + |\bar{y}|$ (неравенство треугольника).

**Определение 3.** Линейное пространство, в котором задана норма, называется **нормированным пространством**.

Евклидовы и нормированные пространства являются линейными пространствами с дополнительными структурами: скалярным умножением и нормой соответственно.

---

# Теорема о связи скалярного произведения и нормы

**Теорема 1.** Всякое скалярное умножение в евклидовом пространстве $E$ определяет норму согласно формуле  
$$|\bar{x}| = \sqrt{(\bar{x}, \bar{x})} = \sqrt{\sum_{i=1}^n x_i^2}.$$  
(1)  

**Доказательство.** Так как $(\bar{x}, \bar{x}) \geq 0$, то функция $|\bar{x}| = \sqrt{(\bar{x}, \bar{x})}$ определена для любого вектора $\bar{x}$ евклидова пространства $E$. Проверим выполнение аксиом нормы:  
a) $|\bar{x}| = \sqrt{(\bar{x}, \bar{x})} \geq 0$, так как $\sqrt{(\bar{x}, \bar{x})} \geq 0$, причем $\sqrt{(\bar{x}, \bar{x})} = 0$, если $\bar{x} = 0$;  
b) $|\lambda \bar{x}| = \sqrt{(\lambda \bar{x}, \lambda \bar{x})} = \sqrt{\lambda^2 (\bar{x}, \bar{x})} = |\lambda| \cdot \sqrt{(\bar{x}, \bar{x})} = |\lambda| \cdot |\bar{x}|$;  
c) из неравенства Коши-Буняковского $(\bar{x}, \bar{y}) \leq (\bar{x}, \bar{x})(\bar{y}, \bar{y})$ следует, что $(\bar{x}, \bar{y}) \leq \sqrt{(\bar{x}, \bar{x})} \cdot \sqrt{(\bar{y}, \bar{y})}$ или $(\bar{x}, \bar{y}) \leq |\bar{x}| \cdot |\bar{y}|$. Тогда  
$$|\bar{x} + \bar{y}|^2 = (\bar{x} + \bar{y}, \bar{x} + \bar{y}) = (\bar{x}, \bar{x}) + 2(\bar{x}, \bar{y}) + (\bar{y}, \bar{y}) \leq |\bar{x}|^2 + 2|\bar{x}| \cdot |\bar{y}| + |\bar{y}|^2 = (|\bar{x}| + |\bar{y}|)^2.$$  
Таким образом, $|\bar{x} + \bar{y}| \leq |\bar{x}| + |\bar{y}|$. Теорема доказана.

# Норма матрицы

Нормой матрицы $A_{m \times n}$ с вещественными элементами в пространстве матриц называют неотрицательное число, обладающее следующими свойствами нормы:
а) $\|A\| \geq 0$, причем $\|A\| = 0$, если $A = 0$;  
б) $\|\lambda A\| = |\lambda| \cdot \|A\|$, где $\lambda \in \mathbb{R}$;  
в) $\|A + B\| \leq \|A\| + \|B\|$ — неравенство треугольника;  
г) $\|A \times B\| \leq \|A\| \times \|B\|$ — для любых матриц из рассматриваемого пространства.  

$$
\|A\vec{x}\| \leq \|A\| \times \|\vec{x}\|.
