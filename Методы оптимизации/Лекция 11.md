# Анализ чувствительности решения

Продавлизируем чувствительность этого решения некоторым параметрам исходной задачи:
1. Насколько можно увеличить запас некоторого вида сырья для улучшения полученного оптимального значения целевой функции
2. Насколько можно снизить запас некоторого вида сырья при сохранении полученного оптимального значения целевой функции
3. Увеличение какого вида сырья наиболее выгодно
4. Какой диапазон изменений каждого коэффициента целевой функции, при котором не происходит изменения оптимального решения

Ограничение называется активным, если соответствующая ему прямая проходит через точку оптимума, иначе ограничение является неактивным.

Таким образом в нашей задаче: L2, L3 – активные, L1 – неактивное.  
L4 – это целевая функция $f(x_1, x_2)$.

# Интерпретация активных и неактивных ограничений

Если ограничение неактивное будем относить его к разряду дефицитных товаров, так как оно расходуется полностью.  
Сырьё, которое не расходуется полностью относится к неактивным ограничениям.

Если ограничение является активным, то будем относить его к разряду дефицитных товаров, так как оно расходуется полностью.

$$y_i = \frac{\Delta f_i}{\Delta S_i}$$

$y_i$ — соотношение значения целевой функции до и после изменения значений данных.

Уменьшая запасы недефицитного сырья, оптимальное значение нецелевой функции не меняется.

Полученные результаты говорят о том, что не важно, что увеличивать, запасы сырья 2 или 3, в конамический эффект будет одинаковым, т.к. $y_2 = y_3$.

# Определения функций Лагранжа

**Определение.** Обобщенной функцией Лагранжа называется функция  
$$L(x, \lambda_0, \lambda) = \lambda_0 f(x) - \sum_{i=1}^p \lambda_i \phi_i (x) = \lambda_0 f(x) - (\lambda, \phi(x)).$$  
где числа $\lambda_i$ – множители Лагранжа.

**Определение.** Классической функцией Лагранжа называется функция  
$$L(x, \lambda) = f(x) - \sum_{i=1}^p \lambda_i \phi_i (x) = f(x) - (\lambda, \phi(x)).$$

**Определение.** Градиентом обобщенной (классической) функции Лагранжа называется вектор-столбец, составленный из ее частных производных первого порядка по $x$.

---

# Градиент функции Лагранжа

**Определение.** Градиентом обобщенной (классической) функции Лагранжа называется вектор-столбец, составленный из ее частных производных первого порядка по $x_i$.

$$\text{grad } L(x, \lambda, \lambda) = L'(x, \lambda, \lambda) = 
\begin{pmatrix}
\frac{\partial L(x, \lambda, \lambda)}{\partial x_1} \\
\frac{\partial L(x, \lambda, \lambda)}{\partial x_2} \\
\vdots \\
\frac{\partial L(x, \lambda, \lambda)}{\partial x_n}
\end{pmatrix},$$

$$\text{grad } L(x, \lambda) = L'(x, \lambda) = 
\begin{pmatrix}
\frac{\partial L(x, \lambda)}{\partial x_1} \\
\frac{\partial L(x, \lambda)}{\partial x_2} \\
\vdots \\
\frac{\partial L(x, \lambda)}{\partial x_n}
\end{pmatrix}.$$

---

# Второй дифференциал функции Лагранжа и дифференциал ограничения

**Определение.** Вторым дифференциалом обобщенной (классической) функции Лагранжа называется:

$$d^2 L(x, \lambda_0, \lambda) = \sum_{i=1}^p \sum_{j=1}^p \frac{\partial^2 L(x, \lambda_0, \lambda)}{\partial x_i \partial x_j} dx_i dx_j,$$

$$\left[ d^2 L(x, \lambda) = \sum_{i=1}^p \sum_{j=1}^p \frac{\partial^2 L(x, \lambda)}{\partial x_i \partial x_j} dx_i dx_j \right].$$

**Определение.** Первым дифференциалом ограничения $\varphi_i(x)$ называется функция $d\phi_i(x) = \sum_{j=1}^p \frac{\partial \phi_i(x)}{\partial x_j} dx_j$.

---

# Определение активных ограничений и постановка задачи

**Определение.** Пусть $x^*$ – некоторая точка, удовлетворяющая неравенствам (3). Ограничения, которые в этой точке выполняются, как равенства будем называть активными. Обозначим через $I(x^*)$ множество индексов, активных в точке $x^*$ ограничений.

Рассмотрим более подробно простую задачу нелинейного программирования с ограничениями типа равенств (4).

$$f(x) \to \min_{x \in U}, \text{ где } U = \{ \phi_1 (x) = 0, \, ... \, , \, \phi_m (x) = 0 \}.$$

Решение этой задачи $x^*$ находит с помощью необходимых и достаточных условий экстремума.

---

# Необходимое условие экстремума (Лемма 1)

**Лемма 1 (необходимое условие экстремума).**

Пусть функции $f(x), \varphi_i(x), i=1, ..., m$ - непрерывно дифференцируемы в $E^n$ и точка $x^*$ удовлетворяет ограничениям типа равенств (4). Тогда для того, чтобы точка $x^*$ была решением задачи, необходимо существование таких чисел $\lambda_0^*, \lambda_1^*, ..., \lambda_p^*$, что выполняются следующие условия:

1) $L'(x^*, \lambda_0^*, \lambda^*) = 0$,  
2) $\phi_1(x^*)=0, ..., \phi_m(x^*)=0$.

Если при этом градиенты ограничений $\{\nabla \varphi_i(x^*) \}, i=1, ..., m$ - линейно-независимы в точке $x^*$, то $\lambda_0^* \neq 0$.

---

# Замечания о необходимом условии

**Замечание.**

1) Точки $x^*$, удовлетворяющие системе (5)-(6) при некоторых $\lambda_0^*$ и $\lambda_i^*$, называются условно-стационарными.

2) При решении задач проверка линейной независимости градиентов ограничений $(\nabla \varphi_i(x^*)), i=1,...,m$ не всегда возможна, так как точка $x^*$ не известна. Поэтому рассматривают два случая: $\lambda_0^* = 0$ и $\lambda_0^* \neq 0$. Если $\lambda_0^* \neq 0$, то полагают $\lambda_0^* = 1$, что эквивалентно нормировке функции Лагранжа и системы (5)-(6) на $\lambda_0^*$. При этом обобщенная функция Лагранжа становится классической. При $\lambda_0^* = 0$ в обобщенной функции Лагранжа исчезает слагаемое с целевой функцией, а для практики представляет интерес случай, когда в функции Лагранжа присутствует целевая функция, экстремум которой ищется. Поэтому в дальнейшем будем рассматривать классическую функцию Лагранжа, когда градиенты ограничений $(\nabla \varphi_i(x^*)), i=1,...,m$ - линейно-независимы в точке $x^*$.

---

# Достаточное условие экстремума (Лемма 2)

**Лемма 2 (достаточное условие экстремума).**

Пусть имеется точка $(x^*, \lambda^*)$, удовлетворяющая системе (5)-(6). Если в этой точке выполняется неравенство  
$$d^2 L(x^*, \lambda^*) > 0 \, (d^2 L(x^*, \lambda^*) < 0) \quad (7)$$  
при условии  
$$d\phi_i(x^*) = 0 \quad (8),$$  
то точка $x^*$ является точкой локального минимума (максимума) задачи (4).

---

# Алгоритм метода множителей Лагранжа

**Алгоритм метода множителей Лагранжа.**

1) Составить классическую функцию Лагранжа:  
   $$L(x, \lambda) = f(x) - \sum_{i=1}^{p} \lambda_i \phi_i(x) = f(x) - (\lambda, \phi(x))$$

2) Записать необходимые условия экстремума (5)-(6) $L'(x, \lambda) = 0$ и $\phi_1(x) = 0, ..., \phi_m(x) = 0$. Решить систему и найти условно-стационарные точки $x^*$.

3) Записать выражение для второго дифференциала классической функции Лагранжа $d^2 L(x^*, \lambda^*)$ в точке $(x^*, \lambda^*)$ и систему $d\phi_i(x^*) = 0$. Из последней системы (7) выразить любые $m$ дифференциалов $dx_i$ через остальные $(n-m)$ и подставить в $d^2 L(x^*, \lambda^*)$.

4) Определить знак $d^2 L(x^*, \lambda^*)$. Если $d^2 L(x^*, \lambda^*) > 0$, то точка $x^*$ является точкой локального минимума. Если $d^2 L(x^*, \lambda^*) < 0$, точка $x^*$ является точкой локального максимума. Если $d^2 L(x^*, \lambda^*) \geq 0$ или $d^2 L(x^*, \lambda^*) \leq 0$, то требуется дополнительное исследование.

5) Вычислить значение функции в точке условного экстремума.
